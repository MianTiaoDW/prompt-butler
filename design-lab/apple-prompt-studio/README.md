# Apple Prompt Studio

这是一套从插件核心任务重新设计的个人创作空间，不继承仓库中既有 Design Lab 的视觉方向，也不采用 B 端后台的侧边栏、列表详情和多面板骨架。

产品结构只保留三条主要路径：

1. 创作：以居中的 Apple Intelligence 式输入入口完成一句描述到专业 Prompt。
2. 提示词库：以 Photos 式作品画廊浏览、收藏和复用内容。
3. 图像工坊：以沉浸画布查看生成结果，通过浮动控件调整和再次生成。

在不改变这套视觉结构的前提下，原型已补回正式插件的主要操作面：

- 创作：参考图计数、最近使用、专家身份、专业工作流、模型、中文 / English / JSON、复制、收藏、常用、AI 优化和进入图像工坊。
- 提示词库：关键词搜索、资产筛选、分类、排序、收藏、收藏夹的新建 / 重命名 / 删除、导入导出入口、编辑、复制、AI 优化和删除确认。
- 图像工坊：Prompt 编辑、比例、分辨率、生成数量、生成状态、下载、保存 Prompt、示例图、再次生成和创作历史。
- 设置：服务商、API Key、Base URL、生图专用连接、三类模型、图像默认参数、示例图存储、保存、测试连接和自动识别模型。

设计原则：

- 常用路径先出现，高级参数渐进披露。
- 不使用永久侧边栏；三项工作区位于底部浮动玻璃 Dock。
- 半透明材质只用于顶层导航和浮动控制，正文与长 Prompt 使用实色表面。
- 暗色使用深黑半透明光学材质、受控红绿环境色和弱内高光；竖屏不对整窗施加高成本模糊，只在关键表面保留模糊。
- 系统蓝只表示当前操作，绿色只表示就绪，粉色只表示收藏。
- Pointer Down 立即反馈；工作区切换使用无弹跳、可中断的短过渡。
- 只迁移线性功能图标，不使用六枚锁定的彩色状态图标；搜索、设置、复制、收藏、编辑、删除和下载均在真实操作位置提供语义动效。
- 功能图标还覆盖筛选、排序、文件夹、更多、编辑、导入导出、保存、刷新、连接状态、返回与历史；六枚冻结图标没有进入页面。
- 提示词详情右上角只保留关闭；收藏、编辑、删除位于正文下方同级操作栏。
- 支持浅色 / 深色、窄屏、Reduced Motion、Reduced Transparency 与 Increased Contrast。

运行：

```powershell
npx vite design-lab/apple-prompt-studio --host 127.0.0.1 --port 4180
```

页面中的提示词库和生成结果仍为演示数据；设置保存到此原型自己的 `localStorage`。它不会读取 Chrome Storage、调用真实 AI API 或进入正式插件构建。
