# 提示词生成管家 · 使用指南

## 1. 安装与打开

1. 打开 Chrome，进入 `chrome://extensions/`
2. 打开右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择项目的 `dist` 目录
4. 加载后工具栏会出现扩展图标，点击即可打开悬浮窗

> 悬浮窗可随意拖拽，在任意网页上使用。

---

## 2. 配置中心（必须）

首次使用需要配置 API 服务商，否则无法生成提示词。

1. 点击悬浮窗右上角的 **齿轮图标** 进入配置中心
2. 依次设置：
   - **服务商**：选择你使用的 API（Claude / Gemini / ChatGPT / Deepseek 等）
   - **API Key**：填入对应服务商的密钥
   - **Base URL**：选择服务商后自动填入，也可手动修改
   - **推理模型**：下拉选择或手动输入模型 ID（如 `claude-opus-4-7`）
   - **视觉模型**：同上（如需传参考图则必填）
   - **生图模型**：同上（如需生成图片则必填）
   - **分辨率 / 比例 / 数量**：根据需求调整
3. 点击 **测试连接**，确认连通
4. 点击 **保存配置**

> 配置保存后悬浮窗顶部状态灯变绿，显示"服务已就绪"即可使用。

---

## 3. 角色设定（生成提示词）

这是核心功能，将简单需求扩写成专业提示词。

1. 切换到 **角色设定** 标签
2. **角色预设**：输入你的角色 JSON 或大白话设定（如"你是 AI 绘画提示词专家..."），点击**保存角色**
3. **用户需求**：输入一句话需求（如"赛博朋克风格的战斗少女"）
   - 可附加一张参考图（点击输入框旁的图片图标上传）
4. 点击 **生成**，等待模型输出
5. 生成结果包含三种格式：
   - **中文段落**：中文画面描述
   - **英文段落**：英文 Prompt（适配主流绘图工具）
   - **结构化 JSON**：分字段的结构化版本
6. 每种格式可 **一键复制** 或 **保存到收藏**

---

## 4. 收藏管理

生成的提示词可以保存、整理、二次优化。

### 保存提示词
- 在"角色设定"页点击 **保存**，选择目标文件夹即可存入收藏

### 文件夹管理
- 切换到 **收藏** 标签
- 点击 **+** 新建文件夹，支持拖拽排序
- 双击文件夹名可重命名，点击文件夹进入查看内容
- 文件夹右上角可删除（删除后提示词回到收藏根目录）

### 提示词操作
- **展开**：查看完整内容
- **一键复制**：复制到剪贴板
- **编辑修改**：手动修改内容
- **AI 一键优化**：调用模型自动优化当前提示词（需要服务已就绪）
- **重命名**：修改标题

### 搜索
- 顶部搜索框输入关键字，按标题/内容/标签/分类跨文件夹搜索

### 导入/导出
- 在 **收藏** 标签页，点击右上角 **下载** 图标导出全部数据（JSON）
- 点击 **上传** 图标导入之前导出的备份文件
- 导入时自动去重，不会覆盖已有内容

---

## 5. 图像生成

将提示词直接生成图片。

1. 切换到 **图像生成** 标签（需先配置生图模型）
2. 提示词输入框会自动带入"角色设定"最后一次生成的内容
3. 也可手动修改或粘贴提示词
4. 调整 **比例 / 分辨率 / 数量**
5. 点击 **生成图片**
6. 生成后可逐张预览、单张下载或 **一键下载全部**

---

## 6. 自定义标签

- 在标签栏最右侧点击 **+** 创建新分类标签
- 双击标签名可重命名，右键可删除
- 每个自定义标签都有独立的文件夹和收藏体系

---

## 常见问题

**Q: 状态灯显示"配置未就绪"？**
A: 检查配置中心是否已保存且测试连接通过。

**Q: 导入 JSON 后文件夹是空的？**
A: 确保 JSON 文件中同时包含 `favorites` 和 `folders` 两个字段。如果导入显示"没有新增内容"说明数据已存在。

**Q: 插件窗口拖不动？**
A: 按住顶部标题栏区域拖动。
